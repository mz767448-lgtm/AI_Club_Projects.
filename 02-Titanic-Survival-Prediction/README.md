# Titanic Survival Prediction 🚢

## Project Overview
This project aims to predict whether a passenger survived the Titanic disaster using Machine Learning classification algorithms.

## Dataset
The dataset contains passenger information such as:
- Age
- Sex
- Passenger Class
- Fare
- Number of Siblings/Spouses
- Number of Parents/Children
- Embarked Port

## Data Preprocessing
- Handling missing values.
- Removing irrelevant features.
- Encoding categorical variables.
- Scaling numerical features.
- Splitting data into training and testing sets.

## Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## Model Evaluation
The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score

## Results
The Random Forest model achieved the highest F1-score (73.85%), while the tuned Random Forest achieved the highest accuracy (81.56%) and precision (83.33%).

## Conclusion
Random Forest provided the best F1-score, while hyperparameter tuning improved accuracy and precision. The results show that different evaluation metrics can lead to different model selections.
